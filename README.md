# Проект. Рекомендательная система в банковской сфере.
## Цель
Предсказать, какой банковский продукт предложить клиенту.
## Основные задачи
1. Анализ данных о клиентах, определение важных метрик,
2. Моделирование,
3. Продуктивизация модели,
4. Настройка мониторинга и дообучения.
## Стек технологий
1. Python
2. Pandas
3. NumPy
4. Matplotlib
5. Seaborn
6. Scikit-learn
